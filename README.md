# Student-Result-Management-System-using-Python
A mini project developed using Python to manage student academic records and results efficiently. This application allows users to add student details, enter marks, calculate grades, and display results through a simple menu-driven program.

Features
Add student records
Enter marks for subjects
Calculate total, average, percentage, and grade
Display student results
Search student by roll number
Update or delete records
File handling for data storage

Python Concepts Used
Variables & Data Types
Operators
Conditional Statements
Loops
Functions
Exception Handling

Objective

The main objective of this mini project is to automate the student result management process and reduce manual calculations.

Outcome

This project helps in understanding how Python can be used to build simple real-time management systems and improves programming logic for beginners.

Python Beginners
